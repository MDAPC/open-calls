# Open Calls

Grants, fellowships, jobs and support for journalists, checked every week.

**Site:** https://mdapc.github.io/open-calls/

**Beta.**

- This first version reads 32 journalism opportunity sites. A wider scanner, with more sources, is coming soon.
- The agentic scanner's code will be open sourced soon.

## How it works

Every week a script reads the sites listed under Resources on the site. Each new item is then opened and checked: is it a real open call, when does it close, who can apply, and where is the organisation's own page. News stories, past winners and closed calls are left out. When a page does not say something, the card says "not stated" instead of guessing.

Some calls first reach us through Hostwriter's members' forum, HostWIRE. We list one only when the organisation's own public page states it, and the card links to that page. Nothing from the forum itself is published.

## Before you apply

Deadlines and rules change. Treat each card as a pointer and read the call on the organisation's own page. Real grants and fellowships do not charge application fees: if a listing asks you for money, do not pay, and tell us.

## Use the data

- `opportunities.json`: the open calls, the programmes we watch, and the full list of sites. Updated with every edition.
- `feed.xml`: RSS of the open calls.
